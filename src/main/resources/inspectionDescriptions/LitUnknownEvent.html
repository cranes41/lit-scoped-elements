Reports @my-event bindings in Lit templates when nothing in the project fires my-event, which often means a typo in the event name.

Fired means new CustomEvent('my-event'), new Event('my-event'), a configured helper call such as this.fire('my-event'), an Event subclass passing the name to super(), a JSDoc @fires my-event tag on an element class, or an entry of a TypeScript event map (interface HTMLElementEventMap). DOM events (click, input, …) are never reported.

Events fired by libraries are only found when Search libraries is on in Settings | Languages & Frameworks | Lit Scoped Elements; otherwise add them to Ignored event names.
