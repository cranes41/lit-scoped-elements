Reports custom elements used in a Lit html`...` template that are not registered in the scopedElements of the enclosing class (Open WC ScopedElementsMixin).

With scoped elements, a tag that is not in scopedElements is not upgraded inside the component's shadow root and silently renders as an unknown element.

Example:


class MyCard extends ScopedElementsMixin(LitElement) {
  static scopedElements = { 'my-button': MyButton };

  render() {
    return html`
      <my-button>OK</my-button>
      <my-icon></my-icon>   // reported: not in scopedElements
    `;
  }
}

Only classes that declare scopedElements or apply ScopedElementsMixin (directly or through a super class) are checked. Entries inherited from a super class or spread with ...super.scopedElements are taken into account.

Templates rendered by a function outside the class (for example function renderRow() { return html`...` }) are checked against the scopedElements of every class that calls that function, directly or through other functions.

Elements defined globally with customElements.define or @customElement in the project are skipped (option Ignore elements defined globally). Use Ignored tag names (regular expressions) for elements defined elsewhere, for example by a library.
