# Privacy Policy – Lit Scoped Elements

Last updated: 24 November 2026

Lit Scoped Elements does not collect, store, or transmit any personal, statistical, or telemetry data.

- All code analysis runs locally in your IDE. Your source code is never sent anywhere by the plugin.
- The plugin makes no network requests and uses no third-party services.
- The plugin's settings (event helper names, the library search option, and event source paths) are saved locally in
  your project's IDE configuration. If you commit that configuration to version control, these settings are shared
  with it.

Your use of the IDE and JetBrains Marketplace is governed by JetBrains' own privacy policy.

If this changes, this policy will be updated before the new version is released.

Questions: https://github.com/cranes41/lit-scoped-elements/issues
